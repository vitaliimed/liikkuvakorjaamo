# Проверки — 08.11.2026

## Пройдены

- Go 1.25.0: сборка самостоятельного сервера и CLI импорта.
- `go test -race -timeout=120s -v ./...` с официальным Firestore emulator 1.19.8: **17 тестов пройдено**, data race не обнаружены.
- 14 проверок бизнес-логики/HTTP: полный цикл, разграничение доступа механиков, запрет пропуска согласия клиента, версия записи, невалидные предложения, неполный отчёт, перенос и повторное согласование, нормализация номера, пересечения времени, стоимость и Helsinki timezone в шаблоне, CSRF/отсутствие аутентификации, ICS-инъекция, запрет неподтверждённой записи в календаре, устаревание уведомлений.
- 3 интеграционных сценария Firestore: конкурентное подтверждение двух пересекающихся выездов (проходит только один), атомарный журнал/освобождение времени при переносе; вход, доступ только к назначенным заявкам и отзыв сессии после блокировки/смены пароля; атомарное сохранение лида+CRM и идемпотентный API-повтор.
- `node --check crm/web/app.js`.
- `node ui-time.test.cjs`: зимнее/летнее время Helsinki, отклонение отсутствующего и повторяющегося часа при переводе часов, экранирование HTML.
- Установщик успешно применён к рабочей копии загруженного архива сайта. Go-тесты приложения прошли с проверенным совместимым набором зависимостей этого пакета + cloudtasks/godotenv. Исходный go.mod живого проекта не проверен; установленный пакет не заменяет его.
- Проверка браузером: главный экран, открытие обращения, цены 50+70=120, форма предложения механика, необязательная причина и обязательный план работ. Обнаруженная несовместимость `crypto.randomUUID` с HTTP preview исправлена на `crypto.getRandomValues`.

## Не проверено в вашем облаке

- IAM, наличие и готовность composite indexes, Secret Manager, реальная политика bucket.
- Реальная загрузка/скачивание изображений GCS, лимит конкурентной загрузки 10 фото на облачном окружении.
- Доставка Telegram и Cloud Scheduler; Meta/WhatsApp не интегрированы.
- Актуальный GitHub/Cloud Run код, исходные текущие зависимости и middleware/rewrite конфигурация домена.
- Автовосстановление данных, резервирование, нагрузочный тест, аудит безопасности внешним специалистом, отдельный мобильный браузер.

Эмулятор не проверяет production IAM и не требует всех составных индексов. Успех этих тестов не означает, что CRM уже работает на основном домене.
