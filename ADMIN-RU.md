# Управление с телефона

Откройте `https://liikkuvakorjaamo.fi/admin` и добавьте страницу на главный экран телефона. Пароль создаётся установщиком и хранится в Secret Manager. Он не записан в архиве. Доступ к админке не следует давать клиентам.

Вверху мобильной версии — выбор раздела и поиск полей внутри текущего раздела. Внизу — одна крупная кнопка **Сохранить настройки**. При несохранённых изменениях браузер предупреждает перед уходом.

## Основные настройки

Вверху находятся:

- Выезд: 70 € по умолчанию.
- Диагностика от: 50 € по умолчанию.
- Основной шрифт: 16–22 px, стандартно 18 px.
- Акцентный цвет в формате `#2458d6`.
- Основной текст, SEO title, description и H1 страниц «Цены», «Зона выезда», «Диагностика».

После изменения цены проверьте главную, страницу цен и собственные рекламные объявления. В произвольных текстах предпочтительны `{visit}`, `{diagnostic}`, `{total}`. Историческая заявка сохраняет цену выезда, действовавшую при её создании: последующее изменение настроек не должно менять согласованную информацию старого клиента.

Стандартные SEO-тексты показываются, если соответствующее поле пустое. Заполненный «Основной текст страницы» заменяет стандартное содержимое описательных карточек; разделяйте абзацы пустой строкой. HTML-код в этом поле не исполняется. Стандартная разметка, форма и навигация сохраняются.

Ниже — контакты, реквизиты, изображения, видимость разделов, аналитика и рекламные ID. Главные тексты и формы FI/EN находятся в собственных разделах. Услуги и примеры работ редактируются карточками.

## Заявки

Откройте «Заявки», выберите клиента, позвоните или отправьте письмо. Статус работы помогает видеть этап: новая, связались, выезд назначен, в работе, ожидаем запчасти, готово, завершено, отменено.

Статусы обработки/Telegram/таблицы относятся к технической доставке. Если запись сохранена, но очередь не приняла задачу, используйте «Повторить обработку». Состояние заявки не следует определять только по наличию Telegram-уведомления.

Фотографии открываются через защищённый адрес `/admin/photo`: вход в админку обязателен. Bucket не публикуется. В Google-таблице хранится техническая ссылка на объект; для удобного просмотра используйте админку или полученный файл в Telegram.

Вложения в письма клиенту: до 10 файлов, всего до 15 МБ. Внешний почтовый сервер также может ограничивать размер. После неоднозначной ошибки SMTP сначала проверьте журнал Brevo, чтобы не отправить повторное письмо.

## Отдельное письмо

Кнопка «Новое письмо» открывает `/admin/email`. Можно указать произвольного получателя, тему, текст и вложения. Заявка не создаётся; Telegram и таблица не меняются. Это отправка письма, не почтовый ящик с историей входящих. Входящие приходят в Gmail через настроенную пересылку.

## Отзывы

Отзывы по личным ссылкам клиентов сначала поступают на модерацию. Публикуйте только действительные отзывы с разрешением автора. Приглашение оставить отзыв не означает автоматическую публикацию.

## Что настраивается в Cloud Shell

Секрет Telegram-бота, SMTP key, пароль админки, токен Apps Script и служебные секреты находятся в Secret Manager, а не в публичном HTML. В админке редактируются только открытые идентификаторы рекламных систем.

Хранилище фотографий нового сайта по умолчанию не удаляет старые файлы по количеству (`GCS_MAX_PHOTOS=0`). Следите за объёмом и определите собственный срок хранения данных. Удаление клиента должно учитывать Firestore, Google-таблицу, фотографии, Telegram и почту; автоматической сквозной очистки во всех внешних сервисах здесь нет.

Перед публикацией проверьте политику конфиденциальности: фактического оператора, адрес для обращений, используемые сервисы и правила хранения. Реквизиты переносятся из действующего AutoHelp только как исходные значения для вашей проверки.
