# Управление сайтом Liikkuva

## Тексты

В /admin?tab=landing-fi откройте «Главная — финский» и поле «Услуги заголовок FI». Для английского откройте /admin?tab=landing-en. Сохраните настройки и обновите страницу сайта. Встроенное значение финского заголовка хранится в source/liikkuva-content.json, раздел fi.Services.Heading.Title. Значение из кабинета имеет приоритет. Тексты формы, услуг, акций, писем и служебных страниц находятся в отдельных вкладках кабинета. Часть служебных подписей остаётся в source/templates и source/static/js. При правке Go, JSON или шаблона нужен новый релиз.

## Посадочные страницы

Откройте /admin?tab=seo. Выберите URL, измените title, description, H1, вводный текст и разделы. Каждый раздел начинается заголовком на отдельной строке, затем идёт текст. Разделитель между разделами — строка из трёх дефисов. Сохраните и проверьте страницу. Только утверждённые цены задаются цифрами в настройках цен. В тексте используйте {visit}, {diagnostic}, {total}.

Для новой финской страницы используйте /palvelut/nimi, для английской /en/services/name. Новая страница начинает работу как черновик. После публикации она получает собственный canonical и попадает в sitemap. Шесть прежних URL защищены от случайного снятия с публикации. Переводы требуют самостоятельного текста.

## Отзывы

Ручное заполнение и шесть примеров доступны на /admin?tab=testimonials. Укажите имя и отзыв на языке публикации, проверьте оценку и выберите «Опубликовать». Черновики скрыты. Переключатель секции отзывов находится в общих настройках. Фотография отображается под текстом. Загрузите фото, дождитесь сообщения готовности и сохраните запись. Исходный файл ограничен 20 МБ. Сайт создаёт JPEG с максимальными размерами 1200 × 900 и удаляет метаданные. Поддержка формата зависит от декодера, включая модуль HEIF в контейнере.

Для приглашения откройте заявку в /admin?tab=leads и нажмите отправку приглашения оставить отзыв. Ссылка персональная. На /admin?tab=reviews откройте «Редактировать отзыв», при необходимости внесите правки и сохраните. Для нового отзыва отдельно нажмите «Одобрить и опубликовать». Оценка клиента сохраняется. Исходные имя и текст сохраняются при первом редактировании.

## Форма при уходе

В /admin?tab=promo включите форму, введите два заголовка и последний день показа. Например, 31.12.2026 означает, что показ закончится в 00:00 01.01.2027 по Хельсинки. В настольном браузере автоматический показ срабатывает при уходе курсора за верхнюю границу один раз за сессию. Кнопка в подвале открывает предложение вручную, в том числе на телефоне. Форма использует существующий обработчик нижней заявки и сохраняет поля после закрытия.

## Проверка SEO в Cloud Shell

Перед публикацией выполните `python3 scripts/audit-public-seo.py > "$HOME/liikkuva-seo-before.csv"`. После публикации повторите с именем liikkuva-seo-after.csv. Реестр содержит HTTP-коды, конечные адреса, title, description, H1, canonical, robots, hreflang, Open Graph, JSON-LD, наличие серверной формы и внутренние ссылки. Скрипт читает публичные страницы из sitemap и не отправляет заявки.

В Search Console откройте «Эффективность → Результаты поиска», выберите Финляндию и сравните последние 28 дней с предыдущими. Экспортируйте страницы и запросы отдельно, затем отфильтруйте каждый целевой запрос и посмотрите список страниц. В «Проверке URL» посмотрите выбранный Google canonical для /palvelualue, /hinnasto, /vikadiagnostiikka, /auton-korjaus-kotona, /auto-ei-kaynnisty и /akun-vaihto. После публикации укажите обновлённый sitemap.xml и запросите переобход приоритетной страницы /palvelualue.
