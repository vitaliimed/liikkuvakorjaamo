# Telegram и доля владельца — 19.11.2026

Выполнено:
- При добавлении или изменении Telegram ID активного механика приветствие с инструкцией ставится в очередь вместе с сохранением сотрудника. Повторное сохранение того же ID не дублирует приветствие. Повторное включение сотрудника отправляет инструкцию заново.
- /start и «Помощь» показывают инструкцию. Telegram требует, чтобы сотрудник сначала открыл @autotfix_bot и нажал Start. Отправка из очереди зависит от работающего Scheduler и доступности бота.
- В списке сначала самые новые заявки (по дате создания); подписи: номер, дата, имя, краткая проблема. Без номера выводится «Без номера». Сохраняется ограничение 50 доступных активных заявок; остальные можно искать по номеру.
- Выбор заявки показывает контакты, адрес, данные автомобиля, источник, статус, время, предложенные или согласованные цены, проблему, план и результат работ. Фотографии и полная история доступны по защищённой ссылке CRM. Механик видит только разрешённые ему заявки.
- Длинные сообщения отправляются частями без обрезания. При сетевой ошибке очередь повторяет отправку; уже доставленная часть может повториться.
- Новые финансовые карточки получают фиксированную долю владельца 50 €. Владелец может изменить её для конкретной заявки в «Сумма, даты и доли». Существующие сохранённые карточки, включая старые без указанной доли, не пересчитываются.
