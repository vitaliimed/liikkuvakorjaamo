## Поведение

- Допустимы только три латинские буквы + три цифры либо три цифры + три латинские буквы.
- `abc123`, `abc 123`, `ABC-123` → `ABC-123`.
- `123abc`, `123 abc`, `123-ABC` → `123-ABC`.
- Порядок символов сохраняется. Лишние символы не обрезаются, неверный номер отклоняется.
- Единые правила Go используются формой сайта, созданием/сменой номера CRM и поиском API.
- Верхняя и нижняя формы FI/EN, CRM-поиск и создание заявки используют одинаковую логику ввода.
- Поиск получил кнопки «Найти» и «Сбросить». В карточках и списках номер отображается с дефисом.
- Ключи Firestore остаются без дефиса, например `ABC123`; данные и связи не мигрируются.
- Старые записи с номером другого формата не удаляются; строгий поиск такого номера теперь выдаёт ошибку. Их можно открыть из списка обращений.
- Сохранённые подсказки администратора с единственным примером ABC-123 дополняются вторым форматом при отображении.

## Обновление через Cloud Shell

Из чистой рабочей папки проекта:

```bash
cd ~/liikkuva
git fetch origin
git switch feat/unified-registration-20261117
git pull --ff-only origin feat/unified-registration-20261117
python3 update.py --project=liikkuva-korjaamo --region=europe-north1 --service=liikkuva-preview
```

`update.py` запускает Go-тесты и проверяет новую ревизию до переключения трафика. В этой задаче Cloud Run не обновлялся. Если `git switch` сообщает о локальных изменениях, не применяйте reset/force: сохраните изменения отдельно перед обновлением.
