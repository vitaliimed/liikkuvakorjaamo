# Бесплатная доменная почта: входящие + отправка

Схема для `service@liikkuvakorjaamo.fi`:

- **Входящие:** Cloudflare Email Routing пересылает письма на ваш существующий Gmail.
- **Исходящие:** Brevo SMTP отправляет подтверждения, ответы из админки и письма с вложениями от нового домена.
- **Админка:** `/admin/email` позволяет написать письмо любому получателю без создания заявки. Вложения — до 10 файлов, суммарно до 15 МБ. Отправка доступна только после входа.

Это бесплатная схема в рамках квот сервисов, а не полноценный отдельный IMAP-ящик. Домен и облачный хостинг оплачиваются отдельно. По документации Brevo на 31.10.2026 Free включает до **300 отправок в сутки**; остаток не переносится. Если используется тот же аккаунт Brevo, лимит общий с AutoHelp. Не рассчитывайте на бесплатную неограниченную рассылку.

## 1. Входящие через Cloudflare

1. Добавьте `liikkuvakorjaamo.fi` в свой Cloudflare и выберите доступный бесплатный тариф.
2. Если DNS домена пока у регистратора, сначала перенесите существующие A/AAAA/CNAME/TXT/MX, затем смените nameservers на выданные Cloudflare. Смена nameservers требует аккуратного переноса уже работающих записей.
3. Email → Email Routing → подтвердите адрес Gmail, куда принимать письма.
4. Создайте custom address **service@liikkuvakorjaamo.fi** → ваш подтверждённый Gmail.
5. Добавьте MX/TXT, которые показывает Cloudflare. При работающей почте у другого провайдера сначала решите, кто принимает письма: не смешивайте два независимых комплекта MX.
6. Отправьте с другого своего ящика письмо на новый адрес и проверьте получение в Gmail.

В этой конфигурации Email Routing обслуживает входящую пересылку, а отправка приложения настроена через Brevo SMTP. Для получения писем подтвердите Gmail и включите правило пересылки; для отправки заполните SMTP-данные ниже.

## 2. Подтвердите домен в Brevo

1. В Brevo откройте **Settings → Senders, Domains & Dedicated IPs → Domains**.
2. Добавьте `liikkuvakorjaamo.fi`.
3. В DNS добавьте **точные** записи подтверждения, DKIM и DMARC, предложенные Brevo. Не копируйте записи AutoHelp: подтверждение относится к конкретному домену.
4. Если сервис просит SPF, используйте выданное значение с учётом других отправителей. На одном имени должен быть один SPF TXT; два независимых `v=spf1` не создавайте.
5. Дождитесь подтверждения домена. Добавьте Sender: **Liikkuva Auto Korjaamo <service@liikkuvakorjaamo.fi>**.
6. **Settings → SMTP & API → SMTP:** скопируйте SMTP login и создайте SMTP key. Нужен **SMTP key**, не API key и не пароль входа в Brevo.

SMTP login может отличаться от адреса входа в Brevo: копируйте именно Login со страницы SMTP. Сервер — `smtp-relay.brevo.com`, порт — `587`; приложение требует STARTTLS перед передачей учётных данных. Также поддерживается TLS-порт 465, если вручную настроить его в Cloud Run.

## 3. Подключите к новому сайту

Из папки комплекта в Cloud Shell:

```bash
python3 "$HOME/liikkuva-release/update.py" --configure-email
```

Введите SMTP login, SMTP key и адрес отправителя. Пароль вводится скрыто. Скрипт записывает отдельные версии секретов нового сайта и обновляет его SMTP-настройки, не меняя AutoHelp. После этого:

1. Админка → Основные настройки → почта для связи: `service@liikkuvakorjaamo.fi`.
2. Проверьте этот адрес в политике конфиденциальности.
3. Отправьте свою тестовую заявку с личным email.
4. В Gmail откройте полученное письмо → «Показать оригинал»: проверьте SPF/DKIM/DMARC. Не должно быть чужого From и неправильного Reply-To.
5. Ответьте на письмо: ответ должен попасть через Cloudflare на ваш Gmail.
6. Админка → Новое письмо: отправьте себе письмо с небольшим PDF. Статус успешной отправки означает приём SMTP-сервером, а не гарантированное попадание во входящие.

Если вы хотите отвечать непосредственно из Gmail под новым адресом: Gmail → Settings → Accounts and Import → Send mail as → добавьте доменный адрес и настройте SMTP Brevo. Подтверждение придёт через Email Routing. Для проверки сначала отправьте письмо себе: иначе Gmail может отвечать вашим личным адресом. Возможности Gmail зависят от типа аккаунта.

## Что означают ошибки

| Ошибка | Проверка |
|---|---|
| 535 / authentication failed | SMTP login и SMTP key, а не API key |
| Sender not verified | Подтверждены ли домен и адрес отправителя в Brevo |
| Нет входящих | MX, подтверждение адреса назначения и маршрут Cloudflare |
| Письмо в спаме | DKIM/DMARC, репутация нового домена, содержимое; проверьте Brevo logs |
| Лимит отправок | Общая квота Brevo с AutoHelp; при необходимости тариф выше |
| Отправка не подтверждена | Сначала проверьте Brevo logs: потеря ответа SMTP иногда происходит уже после приёма письма. Не нажимайте повторно без проверки |
