# Liikkuva — зелёный сайт с оранжевыми акцентами (11.11.2026)

Данный выпуск исправляет чрезмерную оранжевую заливку из ветки `feat/orange-brand-unified`.

- Единый зелёный `#23372b` вместо старых оттенков. Сохраняем зелёную визуальную иерархию рабочего сайта: верхняя полоса, зона обслуживания, основные полноширинные блоки и футер — зелёные.
- Единый оранжевый `#f97315` используется для стрелки логотипа, иконок, акцентных ссылок и кнопок вместо старого синего.
- Логотипы (светлый/тёмный), favicon, FI/EN страницы и фирменные письма — из оригинального нового бренд-комплекта.
- Тёмный режим проверяем отдельно, сохраняя контраст текста.
- CRM и её WhatsApp webhook НЕ затрагиваются этим релизом; это ветка публичного сайта.

## Preview и выпуск

Создавайте Cloud Run ревизию с `--no-traffic --tag=green-orange-preview`. Перед переводом на 100% проверьте HTTP 200 для основных страниц, статическую палитру, обе темы, форму заявки и интеграции. 

ВАЖНО: `LIIKKUVA_BOOTSTRAP=1` блокирует большинство POST-форм, включая `/lead`. Если production/preview содержит такую переменную, не публикуйте «зелёно-оранжевую» ревизию только по результату проверки страниц. Сначала проверьте все интеграции и безопасно включите приём заявок в отдельном этапе. Не меняйте переменную на `0` без проверки конфигурации и теста формы.

На этом выпуске фирменные цвета фиксированы: зелёный `#23372b`, оранжевый `#f97315`. Старые значения акцента в настройках принудительно нормализуются к фирменному оранжевому; другие настройки администратора сохраняются.

## Синхронизация растровых логотипов

Исходные SVG уже содержат точные цвета; публичные страницы используют SVG вместо старых PNG. Чтобы тот же оттенок был в email и иконках устройств, перед выпуском пересоберите PNG/WebP/ICO из SVG, затем добавьте изменённые бинарные файлы в Git:

```bash
cd "$HOME/liikkuva"
python3 -m venv /tmp/liikkuva-brand-venv
/tmp/liikkuva-brand-venv/bin/pip install pillow cairosvg
/tmp/liikkuva-brand-venv/bin/python brand_rasters.py
git add source/static/img/
```

Пока PNG/WebP/ICO не пересобраны и не добавлены в Git, старые растровые файлы могут содержать предыдущий оттенок; не утверждайте, что все экспортные форматы полностью синхронизированы.
