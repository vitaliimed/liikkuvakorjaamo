# Оранжевая айдентика Liikkuva — 11 ноября 2026

Основной акцент `#ff7410`, зелёный футер и шапка письма `#133e32`.
Публичные шаблоны FI/EN, страницы услуг, privacy/review/thank-you, кабинет
и CRM используют одну палитру. Светлая и тёмная темы используют разные
варианты предоставленного логотипа. Instagram — SVG-иконка с доступным именем.

Полный существующий комплект логотипов и favicon из `assets/static/img`
включён в `source/static/img`, который действительно копируется в Cloud Run.
Изменённые изображения имеют версию в URL. Старый стандартный синий акцент
в сохранённых настройках автоматически заменяется оранжевым; другой вручную
выбранный цвет сохраняется.

Клиентские письма используют общий HTML-шаблон: подтверждение заявки,
готовность автомобиля, произвольное письмо по заявке, запрос отзыва.
Язык FI/EN берётся из заявки. Для отдельного письма без заявки добавлен
выбор языка. Введённый менеджером текст не переводится автоматически.
Служебные письма кабинета сохраняют русский текст и получают общий стиль.

Проверено: `go test ./...` и `go vet ./...` в `source`,
`go test ./...` в `liikkuva-crm`, 28 Python-тестов, Node-тесты темы,
аналитики и Apps Script. Браузерная визуальная проверка не завершена:
локальный сервер недоступен браузеру этой среды. SMTP-отправка не выполнялась.

Изменения в Git не означают обновления Cloud Run. Для выпуска используйте
существующий процесс `update.py` из актуальной ветки. Этот скрипт после
проверки ревизии переключает пользовательский трафик; не запускайте его,
если требуется сохранить текущую рабочую ревизию. CRM собирается отдельно.
