# Обновление Liikkuva: форма, изображения, письма и аналитика

Версия приложения: `2026.10.31-client-experience`.

## Обновить сайт

Выполните в Google Cloud Shell одной вставкой:

```bash
(
set -e
git -C "$HOME/liikkuva-release" fetch origin
git -C "$HOME/liikkuva-release" switch codex/liikkuva-client-experience-20261031
git -C "$HOME/liikkuva-release" pull --ff-only origin codex/liikkuva-client-experience-20261031
python3 "$HOME/liikkuva-release/update.py" --configure-media
)
```

Используйте папку `liikkuva-release`: в старой папке `liikkuva` может находиться другая версия установщика. Новый пароль задавать не требуется. Сохранённые параметры почты, Telegram и доступа сохраняются.

Скрипт подключает отдельное закрытое хранилище Liikkuva, проверяет принадлежность проекту, выдаёт сервису доступ к объектам, собирает ревизию без трафика и проверяет её перед переключением. Файлы используют Cloud Storage и учитываются в биллинге Google Cloud проекта. Эта команда не включает приём заявок, если он ранее был приостановлен для настройки интеграций.

## Первый экран и карта

- Форма находится в первом экране слева поверх фотографии на компьютере; на телефоне — сразу после короткого заголовка и цен.
- Обязательные поля публичной заявки: имя и телефон. Email необязателен; при его наличии отправляется подтверждение.
- Скрытый блок дополнительных данных открывается нажатием: адрес, точка на карте, регистрация и фотографии. Поля и файлы отправляются вместе с основной формой.
- Полная вторая форма внизу убрана. Кнопки с других блоков ведут к единственной форме.
- Мобильная закреплённая кнопка скрывается, пока форма видна, чтобы не перекрывать отправку.
- Начальный масштаб обзорной карты приближен к Helsinki, Espoo и Vantaa. Список обслуживаемых городов редактируется отдельно: приближение карты не изменяет границы фактически предлагаемой услуги.
- Информационные блоки о четырёх языках убраны. Переключение FI / EN сохранено.

## Изображения с компьютера

Откройте `/admin?tab=assets`. Для логотипа — `/admin?tab=general`. Для логотипа писем — `/admin?tab=emails`.

1. Найдите нужное поле изображения.
2. Нажмите **Загрузить с компьютера**.
3. Выберите файл и дождитесь сообщения об успешной загрузке.
4. Нажмите **Сохранить изменения**. Пока настройки не сохранены, загруженный файл не подставляется в опубликованную страницу.

| Назначение | Рекомендуемый файл |
|---|---|
| Знак рядом с названием в шапке | Квадратный SVG или прозрачный PNG 256–512 px |
| Знак для тёмной темы | Светлый вариант SVG / PNG, необязательно |
| Знак в письме | PNG 256×256; SVG почтовые программы поддерживают не одинаково |
| Фото первого экрана | WebP / JPG, 1600–2400 px по ширине, желательно до 500 КБ |
| Фото услуг | WebP / JPG, 800–1200 px по ширине |
| Favicon SVG | Простой квадратный знак SVG |
| Favicon PNG | Отдельные размеры 32×32 и 16×16 |
| Favicon ICO | Настоящий ICO; переименование JPG не создаёт ICO |
| Иконка iPhone | PNG 180×180 |

Общий предел загрузки — 8 МБ; PNG / JPG — до 16 мегапикселей и 8000 px по стороне. SVG принимается только без скриптов, CSS, анимации и внешних ресурсов. Фотографии сайта общедоступны. Фотографии клиентов загружайте через заявку: они остаются закрытыми.

Файлы сайта хранятся в `site-assets/`; фотографии заявок — в своём существующем префиксе. Обновление исходников не удаляет загруженные изображения. Ссылка вида `/media/site/…` подставляется автоматически. Git для регулярной замены фото не нужен; ручной вариант по-прежнему доступен через `source/static/img/` и последующее обновление сайта.

## Тёмная тема и логотип

Вместо списка — кнопка с луной / солнцем в шапке, доступная и на телефоне. Выбор запоминается в браузере. Режим сайта по умолчанию и расписание ночи настраиваются в разделе **Основные настройки → Цены и оформление**.

Поле **Логотип для тёмной темы** находится в основных настройках. Если оно заполнено, знак автоматически меняется при переключении. Если поле пустое, основной логотип используется с белой подложкой. Текст названия рядом меняет цвет автоматически.

## Письма

Раздел `/admin?tab=emails` содержит тексты подтверждения и готовности на FI и EN, подписи и логотип. Предпросмотр открывает сохранённый шаблон с вымышленными данными и не отправляет почту.

- Подтверждение отправляется автоматически при обработке сохранённой заявки, если указан email. Текст сообщает, что менеджер позвонит для согласования. Цена выезда берётся из принятой заявки.
- Собственное письмо клиенту отправляется из карточки заявки; отдельное письмо любому получателю — через `/admin/email`.
- Кнопка **Сообщить о готовности автомобиля** в карточке заявки отправляет письмо о готовности по решению команды. Простое изменение этапа работы письмо не отправляет.
- Письма восстановления доступа и приглашения оставить отзыв используют то же оформление.
- Ошибка доставки в Telegram или таблицу не препятствует попытке отправки подтверждения по почте. Статусы доставки сохраняются отдельно.

Поля шаблонов поддерживают `{name}`, `{car}`, `{visit}`, `{diagnostic}`. Обычный текст безопасно преобразуется в HTML; вставлять HTML-код не требуется. Фирменные шапка, контакты и подпись добавляются автоматически. Цвет берётся из настроек оформления.

Наличие SMTP параметров не доказывает доставку. После обновления проверьте получение письма на свой адрес, а также журнал транзакционных писем Brevo. Если в Brevo включена блокировка неизвестных SMTP IP, сервер должен иметь разрешённый постоянный исходящий IP либо SMTP IP-фильтр нужно настроить под выбранную схему.

## Аналитика и события

Раздел `/admin?tab=analytics` показывает действующий ID GA4, включая встроенное значение `G-MXX9XCNCRB`, рекламные идентификаторы и список событий. Настройки считываются при загрузке страницы. Пустой ID использует встроенное значение; отдельный флажок отключает GA4.

Все события приложения включены по умолчанию. События можно отключать по одному; автоматические события Google и расширенная статистика регулируются в GA4 отдельно. Согласие посетителя обязательно для отправки событий GA4. Рекламные теги требуют отдельного согласия на рекламу.

Основная конверсия — **`generate_lead`**, после успешного ответа сервера о сохранении заявки. Повторный вызов с тем же идентификатором в текущем сеансе не создаёт повторную конверсию. `lead_submit_success` — технический ответ формы; не назначайте его второй основной конверсией той же заявки.

Отслеживаются просмотр / начало заполнения / отправка / ошибки формы, добавление фото, использование геолокации и карты, клики телефона / WhatsApp / почты, выбор услуги, просмотр цен и зоны работы, вопросы FAQ, смена темы и версии, глубина просмотра и страница благодарности после заявки. В события не передаются контакты, регистрационный номер, адрес, координаты, текст сообщения, содержимое файлов и имена файлов.

Проверка: **GA4 → Отчёты → В реальном времени**, затем в другой вкладке примите аналитику и выполните действие. Состояние «параметры заданы» в админке не означает, что браузер уже отправил событие в GA4.

## Настройки кабинета

Телефон компании и остальные поля содержимого необязательны. Пустой телефон не мешает сохранить другие разделы; без него кнопки звонка на сайте скрыты. Правила безопасности входа, смены пароля и проверки адреса получателя писем остаются обязательными.

Редактор показывает стандартные опубликованные тексты и карточки услуг, когда сохранённое переопределение отсутствует. Тексты с `{visit}` / `{diagnostic}` используют актуальные цены. Изменения в другой вкладке защищены проверкой версии настроек: конфликт не перезаписывает чужие правки.
